# Using the name "Open Video Menu"

The specification is free to copy, change and implement (see [spec/LICENSE.md](spec/LICENSE.md)). The
*name* is how people know they're getting the real thing, so it comes with a few simple expectations.
They're about clarity, not permission: you never need to ask.

**Always fine**

- Saying your software supports the format: "reads Open Video Menu manifests", "Open Video Menu support".
- Writing about the format, teaching it, or linking to it.
- Naming files with the format's suffix (`.openvideomenu.json`) and using its schema.

**"Compatible"** means passing the [conformance suite](conformance/) for a stated version: "Open Video Menu 0.2
compatible — conformance passed". Run the cases; if they pass, say so. Please don't claim compatibility you
haven't tested.

**Changed versions of the spec** are welcome under the license, under a different name. Please don't call a
modified or extended format "Open Video Menu", or number it as if it were an official version: only versions
published at [openvideomenu.org](https://openvideomenu.org) are Open Video Menu versions (see
[GOVERNANCE.md](GOVERNANCE.md)). If you think the format needs your change, propose it; that's what the
process is for.

**Product names.** Please don't name a product "Open Video Menu" or something easily confused with it
("OpenVideoMenu Player", "Open Video Menu Pro"). "Acme Player, with Open Video Menu support" is perfect.

Written form: **Open Video Menu**, three words. The name was first published with this project; the
domains openvideomenu.org and openvideomenu.com belong to the editor.
