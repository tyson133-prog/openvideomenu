About

An open format, openly run.

Open Video Menu was created by Tyson Treasure, who edits the specification. There's no company or foundation behind it yet, and it doesn't need one: the licenses and the compatibility charter are chosen so the project can move to a neutral home later without anyone's permission.

How the format changes

Changes start as issues and become proposals with conformance cases. Discussion happens in the open; the editor decides, with reasons written down. Only versions published here are Open Video Menu versions.

Growing up

Once there are several independent implementations, the editor will propose a small steering group of implementers, and the specification may move to a neutral steward.

Contributing

Implementations, test reports, importer profiles and spec proposals are all welcome. Contributions to the specification carry the same royalty-free commitment.

Using the name

Clarity, not permission

You never need to ask to use the format or to say you support it. The name tells people they're getting the real thing, so it comes with a few simple expectations.

  • "Supports Open Video Menu" and "reads Open Video Menu manifests" are always fine
  • "Compatible" means passing the conformance suite for a stated version
  • Modified versions of the spec are welcome under another name
  • Please don't name a product "Open Video Menu" or something easily confused with it
